# CodeAtlas — AI Code Review & Engineering Knowledge Portal

A polished, responsive developer portal for repository knowledge, AI-assisted engineering Q&A, pull-request review, security controls, evaluations, and human feedback.

## Features
- Engineering Q&A with citation chips and streaming-style response state
- Pull-request diff review with style/security checks and suggested tests
- Approved documentation and code-snippet knowledge library
- Organization isolation and repository permission controls
- Secret scanning and model usage audit controls
- Evaluation datasets and quality metrics
- Human feedback controls
- Responsive mobile layout with top navigation
- Distinct teal + mint + navy visual system

## Run
```bash
npm install
npm run dev
```
Then open the local Vite address shown in the terminal.

## Build
```bash
npm run build
```

## Tech
React, Vite, Lucide React, CSS.
