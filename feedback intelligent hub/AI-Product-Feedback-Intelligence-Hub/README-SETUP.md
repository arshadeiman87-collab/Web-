# Setup & Demo Guide

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open PowerShell in that folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local Vite address.

### Main demo flows
- **Overview:** KPI cards, sentiment trend, themes, evidence signals.
- **Feedback Explorer:** search + source/sentiment filters + evidence detail drawer.
- **Themes & Clusters:** AI confidence, volume and evidence drill-down.
- **Insights:** evidence-linked product findings.
- **Corrections:** change theme/sentiment and save human corrections.
- **Ingestion:** source connectors and schedules.
- **Exports:** generate demo export jobs.
- **AI Evaluation:** model quality metrics.
- **Team & Workspace:** organization name, members and roles.
- **Privacy:** PII redaction, access logs, retention and model-training controls.
- **Settings:** light/dark mode.

## Notes
This package is a polished front-end demo. API keys, real source credentials, production authentication, database persistence and background schedulers are intentionally represented by functional demo controls rather than fake credentials.
